Tento web

Web je statická stránka na GitHub Pages. Nepoužívá cookies, analytiku ani sledovací skripty a nenačítá nic z cizích serverů. Hostitel (GitHub) může podle svých zásad zpracovávat technické údaje o návštěvě.

Aplikace Travel OS

Aplikace je offline-first: data (cesty, navštívené destinace, lety, checklisty, nastavení) se ukládají v zařízení a bez účtu neopouštějí telefon.

  • Volitelný účet a synchronizace. Po přihlášení se data zálohují do služby Supabase. Účet je potřeba jen pro zálohu, sdílení cest a synchronizaci mezi zařízeními.
  • Sdílené cesty. Data sdílené cesty vidí jen její členové; pozvánka se vytváří na e-mailovou adresu, kterou zadá vlastník cesty.
  • Kurzy měn. Aplikace nejvýše jednou za 24 hodin stáhne kurzy měn z veřejného zdroje; neposílá k tomu osobní údaje.
  • Partnerské odkazy. Odkazy na nabídky partnerů se otevřou v prohlížeči; na jejich stránkách platí zásady daného partnera.
